Criando as máquinas virtuais
<ol>
  <li> Instalar a ISO do Ubuntu via: <a href="https://ubuntu.com/download/server/thank-you?version=26.04&architecture=
amd64&lts=true"> site oficial; </a> </li>
  <li> Abrir o Virtual Box e criar uma nova máquina com as informações:<br/>
    <i>Obs: Optar pela instalação manual</i>
    <ol>
      <li>Memória - 2048MB </li>
      <li>HD - 32GB </li>
      <li>Processador - 1</li>
    </ol>
  </li>
  <li> Iniciar a máquina virtual e realizar a instalação manual do ubuntu </li>
  <li> Configurar idioma e teclado </li>
  <li> Sem proxy </li>
  <li> Selecionar todas as opções de pacotes extra (incluindo network) </li>
</ol>
